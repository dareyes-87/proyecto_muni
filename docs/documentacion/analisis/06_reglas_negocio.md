> Fase: Extracción (parte 3 de 4). Documento de hechos con fuente; no es texto final de la tesis.
> Fecha de extracción: 2026-09-25. Rama: `docs/documentacion`.
> Solo se listan reglas que el código aplica (o decisiones confirmadas por el responsable, R-XX).
> Donde el mensaje del frontend difiere del backend se registran **ambos**.

## Convenciones

- **Dónde se aplica:** Backend (API), Frontend (interfaz), Base de datos (restricción del esquema)
  o Ambos (backend y frontend).
- **Mensaje:** texto exacto que ve el usuario. "B:" = respuesta del backend (el frontend la muestra
  en un *toast* cuando reenvía `error.response.data.error`); "F:" = texto propio del frontend.
  "—" = regla automática sin mensaje.
- **Origen:** "Código" = derivada del código; "R-XX" = confirmada por el responsable
  (`preguntas_abiertas.md`, sección "Respuestas del responsable").
- Rutas abreviadas: `svc/` = `backend/src/services/`, `rt/` = `backend/src/routes/`,
  `pg/` = `frontend/src/pages/`, `cmp/` = `frontend/src/components/`, `schema` =
  `backend/prisma/schema.prisma`.
