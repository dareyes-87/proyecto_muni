# ANEXO C

# REGLAS DE NEGOCIO

Este anexo presenta las 77 reglas de negocio registradas del sistema FarmaG, de las cuales 76 están
vigentes en el commit `bdf1187` y una fue eliminada durante la corrección de defectos. Los
identificadores no se renumeran: la regla eliminada conserva su número. Las 30 reglas de mayor
efecto para el usuario se resumen en la Tabla 46 del capítulo 4.

La Tabla 201 presenta las reglas. La columna "Dónde se aplica" indica si la regla la aplica la API
(backend), la interfaz (frontend), ambas o la base de datos. En la columna "Mensaje al usuario", "B:"
antecede al mensaje que devuelve la API, con su código de respuesta HTTP entre paréntesis, y "F:" al
mensaje propio de la interfaz; un guion indica una regla automática sin mensaje.
